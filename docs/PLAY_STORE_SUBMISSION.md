## 0. 제출 전 선행 조건

| 항목 | 상태 |
|---|---|
| Google Play 개발자 계정 | ❌ 미확보 (등록비 $25 1회) |
| applicationId `com.elid.app` | ✅ 설정 완료 |
| 릴리스 서명 keystore | ✅ 생성 완료 (백업: `C:\Users\mobin_chairman\ELID-Keystore-Backup\`) |
| 개인정보처리방침 URL | ✅ `https://my-elid.com/privacy` (응답 확인 필요) |

**Android는 Apple 계정 없이 진행할 수 있다.** iOS보다 먼저 출시하는 경로가 열려 있다.

## 1. 빌드

```bash
flutter build appbundle --release
# 산출물: build/app/outputs/bundle/release/app-release.aab
```

`android/key.properties`가 있으면 릴리스 키로 서명되고, 없으면 debug 서명으로
폴백한다. **제출 전에 서명 주체를 반드시 확인한다.**

```bash
# APK 기준 확인 (aab는 bundletool 필요)
apksigner verify --print-certs build/app/outputs/flutter-apk/app-release.apk
# → CN=ELID by METI ... 가 나와야 한다
```

## 2. 스토어 등록 정보

| 항목 | 값 |
|---|---|

### 자세한 설명 (초안)

```
ELID는 종이 명함을 대신하는 디지털 명함 서비스입니다.

• 24종 디자인 템플릿으로 나를 표현하는 명함을 만듭니다
• QR 코드와 링크 한 번으로 상대에게 전달합니다
• 받은 명함은 명함첩에 자동으로 쌓입니다
• 그룹과 이벤트로 관계를 이어갑니다
• 채팅으로 명함을 교환한 상대와 바로 대화합니다
• NFC 실물 카드를 신청해 오프라인에서도 사용할 수 있습니다

명함을 주고받는 것에서 끝나지 않고, 연결이 남는 네트워킹을 만듭니다.
```

## 3. 데이터 보안(Data safety) 양식

`ios/Runner/PrivacyInfo.xcprivacy`와 **같은 기준**으로 답한다. 두 스토어 답변이
서로 다르면 나중에 문제가 된다.

| 데이터 유형 | 수집 | 전송 암호화 | 삭제 요청 가능 | 목적 |
|---|---|---|---|---|
| 이름 | 예 | 예 (HTTPS) | 예 | 앱 기능 |
| 이메일 | 예 | 예 | 예 | 앱 기능, 계정 관리 |
| 전화번호 | 예 | 예 | 예 | 앱 기능 |
| 주소 | 예 | 예 | 예 | NFC 명함 배송 |
| 사진 | 예 | 예 | 예 | 프로필·명함 이미지 |
| 앱 내 메시지 | 예 | 예 | 예 | 채팅 |
| 사용자 ID | 예 | 예 | 예 | 계정 식별 |

- **광고·분석 목적 수집 없음**, 제3자 공유 없음
- 데이터 삭제 요청 경로가 있어야 한다 → 계정 삭제 또는 문의 창구를 명시

## 4. 앱 액세스 권한(App access)

로그인이 필요한 앱이므로 **심사용 계정을 반드시 제공한다.**

| 항목 | 값 |
|---|---|
| 사용자 이름 | `(심사용 데모 계정 이메일)` |
| 비밀번호 | `(심사용 데모 계정 비밀번호)` |
| 안내 | 앱 실행 → 시작하기 → 이메일/비밀번호 로그인 → 하단 탭으로 전체 기능 접근 |

- 계정은 **이메일 인증 완료** 상태여야 한다
- 심사 기간 중 비밀번호를 바꾸지 않는다

## 5. 권한 설명

| 권한 | 사용처 |
|---|---|
| 카메라 | QR 코드 스캔, 명함 사진 촬영 |
| 사진/미디어 | 프로필·명함 이미지 선택 |
| 인터넷 | 서버 통신 |

민감 권한(위치·연락처·전화)은 요청하지 않는다.

## 6. 콘텐츠 등급

설문에서 폭력·성적 콘텐츠·도박·약물 항목을 모두 "아니오"로 답하면
**전체 이용가**가 나온다.

> ⚠ 제휴 탭의 해피트리는 게임 콘텐츠지만 **별도 서비스로 연결**되는 것이고
> ELID 앱 자체의 콘텐츠가 아니다. 다만 "다른 앱/웹으로 연결되는 링크가 있는가"
> 항목에는 **예**로 답한다.

## 7. 스크린샷

- 휴대전화: **최소 2장** (권장 5장, 1080×1920 이상)
- 기능 그래픽: 1024×500 (필수)
- 앱 아이콘: 512×512 (필수)

App Store와 같은 구성으로 5장을 쓰면 된다 — 명함 상세 / 디자인 선택 / QR 공유 /
명함첩 / 그룹·채팅.
